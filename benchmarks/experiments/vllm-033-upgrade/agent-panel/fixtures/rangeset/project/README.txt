Repair rangeset.py into a normalized half-open integer range set. Inspect the repository, implement the API, and run the visible tests through tools. Do not modify tests or add third-party dependencies.

RangeSet(ranges=()) accepts an iterable of(start,end)pairs. ranges() returns a new list of sorted nonempty(start,end)tuples with overlap AND adjacency merged. add(start,end) unions a range; remove(start,end) subtracts it and must preserve both surviving pieces. contains(point) tests membership with start<=point<end. clip(start,end) returns the intersection as a new normalized list without changing the set. Endpoints and points must have exact type int(bool and float are not accepted); wrong types raise TypeError. start>end raises ValueError; start==end is empty(add/remove no-op,clip empty). Invalid add/remove must leave the state unchanged. Constructor input and returned snapshots must not remain aliased to internal state. Handle negative values and endpoints up to10**18 by interval arithmetic, never enumerating individual points.
