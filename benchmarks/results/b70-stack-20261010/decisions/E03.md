# E03: Replace existing fused QKV/norm/RoPE

**Decision: NO_MATERIAL_GAIN — profile gate; not implemented.**

The actual existing fused Triton kernel is approximately 0.054/0.060 ms per observed round. The trace has 152 occurrences in eight rounds (16 target plus three MTP attention layers per round). This does not support a useful full-cycle opportunity.

No QKV source port, unrelated MoE/FP8 GEMV patch or prefill dispatch change was made. The profile stop is not a benchmarked loss of every possible QKV implementation.

[Reviewed evidence](../P0-route-and-cost-report.md). These decisions retain FP16, MTP3, original M04, 262144 total tokens, 16 admitted sequences, 180W and the qualified scheduler.
