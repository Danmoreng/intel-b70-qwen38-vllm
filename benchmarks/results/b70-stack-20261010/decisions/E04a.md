# E04a: M04 head-dimension reduction tiling only

**Decision: NO_MATERIAL_GAIN — implemented exploratory operator screen.**

Forty shape/page/mask cases and live-buffer graph mutations passed the original numerical gates; all 40 outputs were bitwise equal to the original M04. Whole-call q4 measurements were near neutral at longer contexts and C4; no useful end-to-end effect was supported.

The upstream reduction idea was adapted to original unnormalized partial outputs and exp2 max/sum merging. Only one bounded paired micro block was measured; it is not a statistically confirmed operator improvement. The original M04 remains selected.

[Reviewed evidence](../E04a-reduction-review.md). These decisions retain FP16, MTP3, original M04, 262144 total tokens, 16 admitted sequences, 180W and the qualified scheduler.
