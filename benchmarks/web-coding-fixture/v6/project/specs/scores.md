# Scores public API

Export createScoreStore(storage, key="flappybird.scores.v1"). storage has getItem/setItem/removeItem methods. No global DOM access at module import. Store API {list,record,clear}. Persist JSON {version:1,entries:[...]}. Each entry is {name,score,frames,seed}: name is a trimmed nonempty string up to 24 characters; score and frames are nonnegative safe integers; seed is uint32. record rejects invalid entries without mutation, copies inputs, keeps the best ten sorted by score descending then frames ascending, and preserves insertion order for exact ties. It returns the same detached list shape as list. list never exposes internal mutable references. clear empties and persists. Reading missing, malformed JSON, unknown version or invalid entries resets safely to an empty list. Throw a clear Error for storage access failure; do not execute stored content or use timestamps/random IDs. New instances recover valid persisted scores.
